# Photon — sugestões de marcos públicos para regressão

`photon-public-landmarks.json` contém respostas **gravadas** do Photon, usadas pelo provedor HTTP local do harness. Não são uma consulta atual nem garantem endereço exato. Consultas e data UTC da coleta constam no JSON. O frontend exige escolha e confirmação do operador, inclusive quando há um número de imóvel.

Origem consultada: Museu de Arte de São Paulo Assis Chateaubriand. Destino: Praça da Sé, São Paulo. São marcos públicos, com cliente, carga e pedido fictícios nos testes. O ensaio público e a prévia ao vivo são separados da regressão determinística.

API: [Photon oficial](https://github.com/komoot/photon/blob/master/docs/api-v1.md). Dados © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
